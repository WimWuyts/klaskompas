# ChatGPT-workflow

ChatGPT begeleidt het project door:

- requirements en beleidsbeslissingen met de gebruiker uit te werken;
- externe research en repository-audits te controleren;
- Claude Code-opdrachten op te stellen;
- handovers, diffs en tests kritisch te reviewen;
- de volgende fase pas te openen wanneer acceptatiecriteria gehaald zijn.

Claude Code bouwt en test. GitHub blijft de duurzame canon.
