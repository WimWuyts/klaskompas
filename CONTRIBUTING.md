# Bijdragen

## Branches

Gebruik korte taakbranches, bijvoorbeeld:

- `docs/behaviour-framework`
- `research/repository-audit`
- `claude/attendance-domain-model`
- `feature/makeup-assessment-workflow`
- `fix/follow-up-status-transition`

## Pull requests

Elke pull request vermeldt:

- doel en scope;
- geraadpleegde canonbestanden;
- genomen beslissingen;
- privacy- en veiligheidsimpact;
- uitgevoerde tests;
- resterende open punten.

## Data

Echte leerlinggegevens zijn verboden. Gebruik uitsluitend gegevens uit `data/examples/` of nieuw aangemaakte, duidelijk fictieve gegevens.
