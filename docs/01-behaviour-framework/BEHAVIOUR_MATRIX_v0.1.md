# Behaviour Matrix v0.1

**Status:** school-aligned design draft; direct L4 response map approved in Phase 1B-D3 and smartphone rule approved in Phase 1B-D6  
**Scope:** ordinary classroom behaviour in English and Spanish lessons  
**Important:** the `Direct classroom response` column contains organisational responses, not automatically official school order measures.

## Approved standard response map — Phase 1B-D3

| Behaviour key | Default L4 response | Approved alternative |
|---|---|---|
| `start_routine_not_followed` | Complete missed routine step | Designated individual start place |
| `instruction_disruption` | Seat change | Separate working position |
| `task_non_start_or_off_task` | Individual task block and checkpoint | Equivalent paper task when digital distraction is causal |
| `peer_distraction_or_group_disruption` | Temporary individual work | Bounded alternative role or work position |
| `unauthorised_smartphone_use` | Device into numbered classroom pouch | None in the ordinary route |
| `unauthorised_laptop_use` | Close device and use equivalent paper task | Reposition screen/seat when digital access remains necessary |
| `reasonable_instruction_not_followed` | Individual position and complete original instruction | Choice between two valid completion routes |
| `disrespectful_language_or_provocation_non_serious` | Separate pupils and pause interaction | Temporary individual work |
| `transition_or_closing_routine_not_followed` | Redo missed routine step | Next transition individually on teacher cue |
| `material_or_space_misuse_non_serious` | Stop and restore | Alternative material under direct supervision |

## Fixed teacher language

### Reminder

> “You are [observable behaviour]. The expectation is [required action]. Do that now.”

### L3 internal classroom record

> “Dit gedrag is na de herinnering blijven doorgaan. Ik noteer dit voor mijn lesopvolging. Als dit opnieuw gebeurt, [directe klasreactie].”

### Direct response

> “It happened again, so the announced classroom response now follows. We can discuss it after the lesson.”

### No debate during instruction

> “I will listen after the lesson. For now, follow the instruction.”

### Respectful disagreement

> “You may disagree. Say what you disagree with without insulting or threatening anyone.”

### Serious incident

> “Stop. Move to [safe instruction]. I am calling the school support route now.”

## Design rules

1. The first two corrections are normally not stored.
2. An L3 internal classroom record is a teacher-private KlasKompas record, never automatically an official warning or order measure.
3. Direct responses must restore learning conditions and be possible immediately.
4. The default response is displayed before L3; the teacher may choose only the approved alternative before announcing the response.
5. At L4 the announced response is applied rather than creating another warning.
6. Formal punishment work, detention, study detention, official agenda notes and temporary removal remain behind the school-authority gate.
7. Genuine learning difficulty, technical failure or approved accommodation is not behaviour misconduct.
8. The system records an individual pupil only when individual behaviour was observed; it does not issue collective class penalties.
9. Serious incidents never wait for a numerical threshold.
10. Refusal of an ordinary L4 response opens the L5 route; it does not automatically impose a formal sanction.
11. Smartphone mode defaults to `prohibited` in every class and stage; temporary pedagogical use is explicit and lesson-scoped.
