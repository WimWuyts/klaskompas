# docs/

Versieerde project- en beslisdocumenten. Dit is **canon** (zie `CLAUDE.md`,
canonvolgorde) — in tegenstelling tot `research/` (inspiratie) en `prototypes/`
(verkenning).

## Structuur

- `00-project/OPEN_DECISIONS_REGISTER.md` — register van open beslissingen die
  bouwtaken kunnen blokkeren of nog bevestiging vragen.
- `adr/` — Architecture/Decision Records: vastgelegde beslissingen, genummerd en
  onveranderlijk van intentie (nieuwe inzichten → nieuwe ADR die de vorige superseden).
- `fiches/` — praktische, snel te raadplegen samenvattingen voor gebruik in de klas.

## Werkwijze

- Een beslissing wordt pas canon als ze door de projecteigenaar is goedgekeurd en in
  een ADR staat.
- Aannames worden expliciet genoteerd als open beslissing, niet verstopt in code.
- Schoolreglement en pedagogisch project staan boven deze documenten; niets hierin
  vervangt een schoolprocedure.
